# 实用小工具

纯前端本地小工具合集，数据只保存在你自己的浏览器里（localStorage），不上传任何服务器。

## 当前功能

- **每斤换算**：输入标价和克重，自动算出每斤 / 每100克价格；按名称记录历史，输入相似名称时自动弹出过去的记录对比。
- **纸品对比**：面巾纸 / 卫生纸 / 厨房纸按每张价对比，支持「同标准 + 同层数」分组，内置生活用纸国标速查（GB/T 20808、GB/T 20810、GB/T 26174、GB 4806.8）。
